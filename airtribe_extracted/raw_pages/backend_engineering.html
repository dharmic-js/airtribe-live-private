DSA: Java / Python

Data structures, algorithms and interview problem solving, in the language you pick

[ 9 Topics ]

Topic 01

Complexity & brute-to-optimal thinking

Time and space complexity, trade-offs and a repeatable framework for improving brute-force solutions

Topic 02

Core linear patterns

Arrays, hashing, prefix sums, two pointers, sliding windows, binary search, stacks, queues and deques

Topic 03

Linked structures, recursion & backtracking

Linked-list transformations, slow/fast pointers, recursion trees, subsets, permutations and pruning

Topic 04

Trees, BSTs & tries

Traversals, BFS/DFS, tree decomposition, lowest common ancestor, BST validation and prefix search

Topic 05

Heaps, intervals, greedy & bit manipulation

Top-K selection, two-heap patterns, sweep-line reasoning, scheduling, greedy proofs and compact state

Topic 06

Graph algorithms & connectivity

Graph modeling, BFS/DFS, topological sorting, cycle detection, Dijkstra and union-find
